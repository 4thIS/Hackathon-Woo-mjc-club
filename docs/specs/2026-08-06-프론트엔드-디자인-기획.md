# 프론트엔드 디자인 기획 — MJC Club Archive

목업으로 확정한 내용의 정리본. 목업 원본은 `mockups/` (main.html · archive.html · club.html · palette.html).
**여기 없는 페이지는 이 문서의 토큰·컴포넌트·패턴을 그대로 따라 만든다.** 새 색·새 간격·새 모서리값을 만들지 않는다.

## 1. 브랜드

- 서비스명: **MJC Club Archive** / 부제: `mjc hackathon project with Woo`
- 태도: 소개글 대신 활동 기록을 먼저 보여준다. 화면도 같은 태도 — 장식보다 기록(카드·타임라인)이 주인공
- 학교 로고: 브랜드 섹션에 들어감. 공식 파일을 `assets/mjc-logo.svg` 로 받아 교체 (자리표시자 유지 중)

## 3. 타이포그래피

- 폰트: **Pretendard** (CDN), fallback `system-ui, "Malgun Gothic"`
- 페이지 대제목(Archive·동아리명): `clamp(30px~52px) / 800 / letter-spacing -.03em` — 단 브랜드 타이틀(MJC Club Archive)만 **weight 400** (스케치 확정)
- 섹션 제목: 20~22px / 700 / -.025em
- 카드 제목: 14~16px / 700
- 본문: 14~15px / line-height 1.75~1.9
- 보조: 12~13px / `--dim`
- 숫자는 전부 `font-variant-numeric: tabular-nums`
- 눈썹 라벨(eyebrow): 10.5~11.5px / 700 / letter-spacing .12~.15em / `--dim`

## 4. 공통 형태 언어

| 요소 | 값 |
|---|---|
| 경계선 | 1.5px solid `--line` (구분선은 1px) |
| 모서리 | 카드 18~20px · 시트 22px · 버튼 10~11px · 입력 11~12px · 칩 999px |
| 그림자 | 기본 `0 5px 16px var(--shadow)` → hover `0 12px 34px var(--shadowUp)` + `translateY(-2~-3px)` |
| 포커스 | `outline: 2.5px solid var(--accent); offset 3px` — 절대 지우지 않는다 |
| 전환 | hover .16s / 등장 .5~.62s ease |
| 헤더 | 높이 64px sticky, `--bg` 88% + blur(10px), 하단 1px 선 |

**버튼 3종** — 이 외 변형 금지:
- `btn` 채움: `--accent` 바탕 + `--onAccent` 글자, 700
- `btn ghost`: 투명 + 1.5px `--line` 테두리
- `btn icon`: 36×36 정사각 (테마 토글 등)

**헤더 구성** (모든 페이지 동일): 로고(텍스트) · nav(홈/둘러보기/동아리 개설, 현재 페이지 700) · 우측(◐ · 로그인 ghost · 회원가입 채움). 로그인 후엔 우측이 내 정보/동아리 관리/관리자로 바뀜 (기획서 §8 권한별).

## 5. 페이지별 확정 사항

### 5.1 메인 (`main.html`) — 스크롤 2단 스냅

```
[헤더 64]
[① 캐러셀  100vh − 64 − 타이틀높이]   ← scroll-snap 1
[② 타이틀 148~188px + 브랜드 섹션]     ← scroll-snap 2 (타이틀이 경첩)
```

- `html { scroll-snap-type: y mandatory; scroll-padding-top: 64px }`, ②에 `scroll-snap-stop: always`
- **타이틀 블록은 ②의 첫 요소.** 최상단에선 화면 맨 아래에 걸쳐 보이고, 한 칸 내리면 헤더 밑에 붙는다. JS 없음 — 배치로 해결
- 스크롤 하이재킹 아님. `prefers-reduced-motion` 이면 `scroll-behavior:auto`

**캐러셀** — 4this_web 기하 이식. 값은 확정, 임의 변경 금지:
```
R:1500  big:1.5  small:0.25  tilt:0.42  stepPx:268  stem:36
cardH:164  damping:0.94  clickSlop:6
무대 높이 660px 미만이면 big 1.5 → 1.26 (카드 상단 잘림 방지)
```
- 카드 = 공개 활동 글. **내용은 사진 + 제목 2줄만.** 동아리명은 호 위 SVG 라벨로 (레퍼런스의 날짜 자리)
- 카드 위아래 번갈아 매달림, 드래그 + 관성, 6px 미만 이동은 클릭(→ 글 상세)
- 트랙 양 끝에 마감 눈금. 우하단에 `↔ 드래그해서 넘기기` 힌트(2.6s 흔들림)

**브랜드 섹션** — 좌: 학교 로고 / 우: 서비스 설명 2문단 + 지표 4개(등록 동아리·모집중·활동 기록·분야) + 우하단 `아카이브 바로가기 →` (hover 시 화살표 4px 전진)

### 5.2 아카이브 (`archive.html`) — 별도 페이지

```
[좌 레일 sticky 260~30%]  [우 인덱스 grid 3열]
```

- **우측**: 카테고리 그룹을 `display:grid; 3열` 로 배치 — 한 줄의 그룹은 같은 높이에서 시작, 다음 줄은 가장 긴 그룹 아래에서 나란히 시작 (columns 흘리기 아님, 확정)
- **36px 베이스라인 그리드**: 그룹 = 제목 36 + 여백 18 + 항목 36×n + 아래 54 → 항상 36의 배수. 항목 행 높이 36px 고정
- 목록 폭 `--colw: 248px` 고정 + 가운데 정렬 → 세로줄 3개가 정확히 맞음
- 항목: `● 이름 (hover 시 N명)` — 점 채움=모집중, 빈 원=마감. 긴 이름 말줄임 + title 툴팁
- 그룹 제목: 가운데 정렬, 분야색 사각점 + 이름
- **좌 레일**: Archive(대제목, 400 아님 — 800) · 부제(개수/찾음 수) · 검색창(× 버튼, 네이티브 cancel 숨김) · 분야 파셋(색점+개수) · 모집 파셋 · 범례
- 검색: 실시간, 매칭 글자는 **색+굵기로만** 강조 (`mark` 배경 금지 — 한글 벌어짐)
- 빈 결과: "찾는 동아리가 없어요" + 개설 유도
- 반응형: 1180px 2열 → 560px 1열, 820px에서 레일이 위로

### 5.3 동아리 상세 (`club.html`)

```
[동아리명 가운데 대제목]
[사진 4:5 34%] [가입신청·인원 버튼 → 소개 2문단 → 정보표]
[활동 기록 타임라인]
```

- 정보표: 분야(칩) · 정기모임 · 창립(N년째 계산) · 지도교수 · 현재 기수 — dt 96px / 1px 행 구분선
- `가입 신청`(채움) + `인원 N`(칩형, N=활동중+OB) 은 소개 위 오른쪽

**타임라인** — 가운데 축, 좌우 번갈아(오른쪽부터), 오래된 순:
- 행 = grid `1fr / var(--axis:150px) / 1fr`. 축 토막은 행마다 소유(`slot.axis::before`) — 행이 나타날 때 선도 자란다
- 마디(11px 원, `--bg` 4px 링) + 연결선(accent 55%, 화살촉) + 연결선 위 날짜
- 카드: 사진 190px + 제목 + 본문 3줄 말줄임 + 태그칩
- **배치 로드**: 처음 5건 → 바닥 260px 전에 다음 5건. 대기 표지 `│ ● 스크롤하면 N건이 더 나옵니다`(pulse 1.5s) → 끝나면 `● 여기까지가 공개된 활동입니다 / YYYY년부터 N건`
- **등장 애니메이션**: `opacity 0 + blur(7px) + ↓28px` → 제자리, 0.62s. 카드 본체 0.08s 지연. IntersectionObserver(`-12% rootMargin`), 한 번 드러나면 unobserve
- `prefers-reduced-motion`: 전건 즉시 렌더 + 애니메이션 생략
- 모바일(≤900px): 축 좌측 14px, 카드 한 줄, `--axis` 56px

**모달 3종** — 네이티브 `<dialog>.showModal()` (ESC·포커스트랩·스크롤잠금 공짜). 배경 클릭 닫기만 추가:
1. **가입 신청** (모집중): 동아리장 가입폼 렌더 + 🔒 "이름·학과·학년만 전달" 고지 + 취소/신청하기
2. **모집 아님**: narrow 시트 — "현재 모집중이 아닙니다" + 다음 모집 안내
3. **인원**: 기수별 그룹(12기 → … → OB). 제목행 `12기 · N명 ─────`, 부원은 알약칩(이름+학과), 동아리장에 accent 배지, OB 그룹 opacity .72

시트 공통: `min(560px)`(narrow 420px) · radius 22 · sticky 헤더(제목+부제+✕) · 하단 버튼행

## 6. 남은 페이지 제작 규칙

내 정보 / 글 작성(AI) / 관리 콘솔 / 관리자 등 남은 화면은:

1. **토큰만 쓴다** — §2 색, §3 타이포, §4 형태. 새 값 금지
2. **모달은 전부 `<dialog>`** — 로그인/회원가입/위임 포함. 시트 구조(§5.3) 재사용
3. **폼 요소**는 club.html 가입폼 스타일: label 13px 700 · 필수표시 `--accent` * · 입력 1.5px `--line` → focus `--accent` · hint 12px `--dim`
4. **개인정보 고지**가 필요한 곳은 🔒 privacy 박스(`--chip` 바탕) 패턴 재사용
5. **경고/안내**는 warn 3색 박스 (AI 메모 요구 등)
6. **빈 상태**는 아이콘 + 한 줄 제목 + 보조설명 + 다음 행동 버튼 (archive 빈 결과 패턴)
7. **관리 콘솔도 같은 톤** — 별도 어드민 테마 만들지 않는다. 헤더 우측 메뉴만 달라짐
8. 등장 애니메이션은 상세 타임라인에만. 다른 페이지는 hover 전환만 (과용 금지)
9. `prefers-reduced-motion` · `:focus-visible` · 키보드 조작은 전 페이지 필수
